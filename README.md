# LeetLite ⚡

[LeetLite live link](https://shivanshsanoria1.github.io/LeetLite/index.html)

A lightweight, lightning-fast, and completely Free and Open Source (FOSS) alternative for browsing algorithmic programming problems, built purely for speed and efficiency.

## 🚀 What is LeetLite?
LeetLite is a static web application designed to eliminate the heavy backend frameworks, complex UIs, and server-side delays of modern coding platforms. Built entirely with Vanilla HTML, CSS, JavaScript, and Bootstrap 5, it uses pre-computed JSON files as its database. This ensures instant navigation, real-time filtering, and zero network lag during your interview preparation.

## ✨ Core Features
- **⚡ Lightning-Fast Search:** Instantly search through thousands of problems by ID or Title using dynamic keystroke events (no "Enter" needed).
- **🔍 Advanced Filtering & Sorting:** Seamlessly filter by Difficulty, Free/Paid status, Categories, and Multi-select Topic Tags. Click any table header to instantly sort by Acceptance Rate, Like Ratios, or Difficulty.
- **💾 Persistent User Settings:** Your search queries, filters, and sort preferences are automatically saved to your browser's `localStorage`, keeping your workspace exactly how you left it.
- **🖥️ Dynamic Split Workspace:** An adjustable, resizable split-pane layout. 
  - *Left Pane:* Problem statements, LaTeX math rendering (via MathJax), collapsible hints, and dynamically mapped similar questions sorted by ID.
  - *Right Pane:* A clean code viewer featuring custom, handwritten solutions crafted strictly by the creator across multiple languages (C++, JavaScript, MySQL).
- **📊 Aggregated Statistics:** Real-time metrics and counters for total problems, free/paid ratios, and difficulty breakdowns (Easy, Medium, Hard).

## 🛠️ Tech Stack
- **Frontend:** Vanilla HTML5, CSS3, JavaScript (ES6+)
- **UI Framework:** Bootstrap 5 (Native Dark Mode support)
- **Data Architecture:** Pre-computed static JSON files
- **Math Rendering:** MathJax 3

## 🏃‍♂️ Running Locally
Because LeetLite is a 100% static site without a backend server, running it locally is incredibly simple:
1. Clone the repository.
2. Serve the directory using any standard static server (e.g., VS Code Live Server, `python -m http.server`, or `npx serve`).
3. Open `index.html` in your browser.
